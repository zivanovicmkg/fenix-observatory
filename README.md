# The Cell-State Observatory

Public FENIX2501-034 project page. The page is a static HTML snapshot dated 1 October 2026. Progress counts are derived from the project's own run records. Dataset maps are the embeddings published with each public dataset (Bastidas-Ponce et al., Development, 2019; Setty et al., Nature Biotechnology, 2019; Pijuan-Sala et al., Nature, 2019), subsampled to 900 cells and redrawn; terrain surfaces are the density of those embeddings, vertically exaggerated. The flow field is a synthetic illustration and is labelled as such. No scores, rankings, runtimes or other unpublished research results appear on the page, and no private command-room data.

The PRACE–FENIX acknowledgement follows the [2025 call terms](https://prace-ri.eu/wp-content/uploads/FENIX-2025-Call-text-v08_clean.pdf), with CINECA as the hosting site.

For GitHub Pages, publish the `main` branch from the repository root. Update `index.html` when a new reviewed public snapshot is ready.
