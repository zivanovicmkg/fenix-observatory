The Cell-State Observatory
Public project page for FENIX2501-034, "State-based analysis of human scRNA-seq data using RNA velocity", a twelve-month PRACE–FENIX allocation hosted on CINECA GAIA Cloud.
Live: https://observatory.biology2.net
The page is a static HTML snapshot dated 10 October 2026. Progress counts are derived from the project's own run records. Dataset maps are the embeddings published with each public dataset (Bastidas-Ponce et al., Development, 2019; Setty et al., Nature Biotechnology, 2019; Pijuan-Sala et al., Nature, 2019), subsampled to 900 cells and redrawn; terrain surfaces are the density of those embeddings, vertically exaggerated. The flow field is a synthetic illustration and is labelled as such. No scores, rankings, runtimes or other unpublished research results appear on the page, and no private command-room data.
The PRACE–FENIX acknowledgement follows the 2025 call terms, with CINECA as the hosting site.
